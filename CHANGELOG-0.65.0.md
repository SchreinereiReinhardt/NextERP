# NextERP 0.65.0

- Zugeordnete Angebots-PDFs können als ERP-Angebot übernommen werden.
- Kunde und vorhandenes Projekt werden übernommen.
- Falls das Projekt noch nicht existiert, kann es beim Import automatisch angelegt werden.
- Originaldokument und ERP-Angebot bleiben bidirektional verknüpft.
- Doppelte Übernahme desselben Dokuments wird verhindert.
- Beträge, Belegdatum und Belegnummer werden als Grundlage übernommen.
