# Betrio 1.9.25

## Mobile Projektnotizen

- Neuer authentifizierter Mobile-API-Endpunkt:
  `POST /api/mobile/v1/project/{id}/notes`
- Native Android-Projektnotizen werden jetzt in `re_erp_order_notes` gespeichert.
- Projektzugriff wird serverseitig geprüft.
- Unterstützte Notiztypen werden auf die vorhandenen Servertypen abgebildet.
- Titel wird zusammen mit dem Inhalt dauerhaft gespeichert.
