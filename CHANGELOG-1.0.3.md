# NextERP 1.0.3 – Projektfreigaben

- Projektzuweisung pro Monteur/Mitarbeiter im Projektcenter
- Ordnerfreigaben pro Mitarbeiter
- Web-Projektliste für Monteure auf zugewiesene Projekte begrenzt
- Direkter URL-Zugriff auf nicht freigegebene Projekte serverseitig gesperrt
- Rapport- und Zeiterfassungsprojektlisten auf freigegebene Projekte begrenzt
- Projektdokumente werden aus dem Besitzer-Projektordner gelesen und nach Ordnerfreigabe gefiltert
- Uploads in nicht freigegebene Projektordner werden blockiert
- Kaufmännische Projektbereiche bleiben für Administration/Büro/Projektleitung reserviert
