# NextERP 0.26.0

- Kunden können mit vorhandenen Nextcloud-Kontakten verbunden werden.
- Kontaktname, Telefon, E-Mail und Anschrift lassen sich aus Nextcloud Contacts synchronisieren.
- Kontaktverbindungen können aktualisiert oder getrennt werden.
- Unter Einstellungen kann ein beschreibbarer Nextcloud-Kalender gewählt werden.
- Neue Teamtermine werden nativ in den ausgewählten Nextcloud-Kalender geschrieben.
- ERP-Termine zeigen an, ob sie erfolgreich an Nextcloud Calendar übergeben wurden.
