# NextERP 1.2.4 – Mobile Dokumente & Fotos

- Eigene mobile Dokumentenansicht je Projekt.
- Ordnerfreigaben werden serverseitig berücksichtigt.
- Dokumente können direkt mobil geöffnet werden.
- Eigene mobile Fotogalerie je Projekt.
- Fotoaufnahme über die Handykamera (`capture=environment`).
- Fotos werden automatisch in `07_Fotos` des aktuellen Projekts gespeichert.
- Optionale Beschreibung wird in der Projektaktivität protokolliert.
- Foto-Upload nur bei freigegebenem Fotoordner.
- Keine Datenbankmigration.
