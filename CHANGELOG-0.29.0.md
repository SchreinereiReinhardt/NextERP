# NextERP 0.29.0 – Native DAV Core

- Kontakte werden direkt aus den Nextcloud-DAV-Adressbüchern und vCards gelesen.
- Kontaktimport zeigt die tatsächlich gespeicherten Nextcloud-Kontakte.
- Neue ERP-Kunden können als echte Nextcloud-vCards angelegt und aktualisiert werden.
- Kalender werden direkt aus dem Nextcloud-DAV-Kalenderspeicher geladen.
- Termine vom Handy und aus Nextcloud Calendar werden aus den echten iCalendar-Objekten übernommen.
- Neue NextERP-Termine werden als native CalDAV-Ereignisse gespeichert.
- Alte, nicht mehr verfügbare Kalenderauswahlen werden eindeutig gemeldet und können neu ausgewählt werden.
- Integrationscenter zeigt den Provider „Native DAV“.
