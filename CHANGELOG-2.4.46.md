# Betrio 2.4.46

- Nextcloud Collaborative Tags werden bei Projektdateien direkt aus Nextcloud Files gelesen.
- Tags werden in der Projektakte an den jeweiligen Dokumenten angezeigt.
- Projektdateien können in Betrio nach vorhandenen Collaborative Tags gefiltert werden.
- Die bestehende Ordnerstruktur und Uploadlogik bleiben unverändert.
- Betrio verwaltet oder dupliziert die Tags nicht; Nextcloud Files bleibt die führende Quelle.
